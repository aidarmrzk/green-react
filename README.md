# Чат MAX

Тестовое задание: текстовый чат на React и TypeScript с подключением к MAX через GREEN-API.

## Запуск

Нужен Node.js 22.12 или выше.

```bash
npm ci
npm run dev
```

Приложение откроется по адресу http://127.0.0.1:5173. Для сборки — `npm run build`, для просмотра сборки — `npm run preview`.

## Подключение

Создайте инстанс MAX в [GREEN-API](https://console.green-api.com/) и авторизуйте его. В настройках включите `incomingWebhook`, а `webhookUrl` оставьте пустым. Для статусов доставки нужны `outgoingWebhook` и `outgoingAPIMessageWebhook`.

В приложении введите `idInstance` и `apiTokenInstance`. Адрес сервера задан в коде: `https://4100.api.green-api.com`.

Чтобы начать переписку, нажмите «Новый чат» и введите номер собеседника. Поддерживаются номера +7 и +375; российский номер с 8 также можно вводить.

## Работа с чатом

- При открытии чата загружаются последние 20 сообщений.
- Новые сообщения приходят через HTTP long polling: `receiveNotification`, затем `deleteNotification` после обработки.
- Enter отправляет сообщение, Shift+Enter переносит строку. Лимит — 4000 символов.
- После успешной отправки появляется галочка. Доставка и прочтение обновляются по уведомлениям GREEN-API.
- При ошибке отправки текст остаётся в поле ввода.

Вход и список чатов сохраняются в localStorage. После перезагрузки выбранный чат восстанавливается, а сообщения загружаются с сервера. «Выйти» удаляет сохранённые данные входа. Черновики не сохраняются.

Для одного инстанса используйте одну вкладку: очередь уведомлений общая. Файлы и групповые чаты не поддерживаются.

## Структура

`src/app` — корневые компоненты и стили. В `src/features/auth` находится вход, в `src/features/chat` — компоненты чата, хуки, обработка сообщений и хранение списка чатов. Общие типы, настройки, API-клиент и элементы интерфейса лежат в `src/shared`. Тесты находятся рядом с соответствующими модулями.

[Документация GREEN-API для MAX](https://green-api.com/v3/docs/)
